# RAGAS 企业级 RAG 评测记录

评测日期：2026-08-10

## 1. 评测设计

- 数据规模：75 条，包含 10 条 Smoke、50 条 Regression、15 条封存 Holdout。
- 覆盖领域：风险合规、信息披露、交易安全、定价建议、证据不足拒答。
- 问法类型：改写、口语、噪声、对抗否定、多约束、多跳和信息不足。
- Gold 口径：使用逻辑知识 ID，通过标题或内容特征归一重复文档与 reindex 后的新物理 `docId`。
- 隔离要求：评测接口不得写入会话记忆、长期记忆或知识缺口；本次覆盖率为 100%。
- 数据治理：校验脚本确认三份数据集共 75 条，Holdout 与 Smoke/Regression 无问题文本泄漏。

确定性门禁：ID Context Recall >= 0.90、ID Context Precision >= 0.55、逐例完整召回率 >= 0.90、Retrieval P95 <= 4000ms、技术错误数为 0；同时检查分类、问法和难度分组指标。

## 2. 结果

| 数据集 | 结论 | ID Precision | ID Recall | 完整召回 | Retrieval P95 | E2E P95 |
|---|---|---:|---:|---:|---:|---:|
| Smoke 10 | PASS | 0.7000 | 1.0000 | 10/10 | 324ms | 4093.1ms |
| Regression 50 | PASS | 0.6623 | 1.0000 | 50/50 | 310ms | 3600.8ms |
| Holdout 15 | RISK | 0.5667 | 0.7333 | 10/15 | 261ms | 2857.3ms |

Regression 的 ID Precision 95% Bootstrap CI 为 0.5830-0.7377，ID Recall CI 为 1.0000-1.0000。Holdout 的 ID Precision CI 为 0.3778-0.7556，ID Recall CI 为 0.5333-0.9333，样本仍小且波动明显。

## 3. 结论

当前版本可以判定为“已通过已知场景发布回归与性能门禁”，不能判定为“企业级 RAG 泛化验收全部通过”。Holdout 的主要缺口位于交易安全、价格多约束和拒答依据，说明对未知表达的业务意图分解与多证据保留仍需增强。

本轮相较旧基线的改善来自以下工程变更：

1. 向量与 ES BM25 并行检索，Query Rewrite 分支并行执行，并对通道设置超时边界。
2. 使用业务概念归一、确定性 Rerank、MMR 去冗余和 Dynamic TopK，补充设备标识篡改、电子烟、管制刀具和规则依据等高区分度概念。
3. 用逻辑知识目录消除重复文档和 reindex 导致的物理 ID 漂移。
4. 新增只读评测入口和分阶段时延字段，排除 L2/L3 写入等副作用对 E2E 时延的污染。

Regression E2E P95 从早期约 8.61s 降至 3.60s；该数据来自同一项目环境的评测报告，不等同于生产压测结果。

## 4. 下一轮规则

1. 不直接根据 Holdout 原句增加关键词或特判。
2. 将失败类型抽象为新的开发样例，并补充同类但不同措辞的 Regression 数据。
3. 完成架构级修复后，重新构造来源独立、未参与调参的 Holdout v2。
4. 确定性检索门禁稳定后，再使用独立 Judge 模型评估 Faithfulness、Answer Relevancy 和答案级 Context Precision/Recall。

本次未运行 LLM Judge，因此报告中的自然语言答案忠实度与相关性仍为待验项；不能用 ID 指标替代答案质量指标。
