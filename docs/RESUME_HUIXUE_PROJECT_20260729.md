# 回血集市 - AI 商品发布与智能运维助手　　　　　　　　　2025.11 - 至今

**使用到的技术栈：** Spring Boot + Spring AI + MySQL + Redis + Elasticsearch + Milvus + RabbitMQ + Vue3

**核心模块：** AI 商品发布助手 + 智能知识检索 + 知识库管理 + 智能运维排查

**开发过程的核心问题与解决方案：**

- **AI 商品发布助手：** 将 AI 嵌入商品发布流程，根据标题、成色和凭证生成文案、风险提示及规则证据；支持 WebSocket 流式输出、建议采纳、证据不足拒答和价格防编造，Source Hit 与拒答准确率均达到 96.83%。
- **智能知识检索：** 针对口语化问法与文档术语不一致，设计动态 Query Rewrite，融合 Milvus 向量召回与 Elasticsearch 关键词检索并使用 RRF 排序；相较纯关键词 Recall@5 提升 6.56%，61 条 hard case 中 Recall@5 达到 100%、MRR 为 0.93。
- **知识库管理：** 支持 Markdown、PDF、Word 解析和结构化切片，通过 RabbitMQ 异步执行入库任务；使用统一 chunkId 对齐 DB、ES、Milvus，新版本校验后再生效，抽样 20 个文档三存储一致率达到 100%，强制重建 P95 为 1.61 秒。
- **智能运维排查：** 提供统一内部排查入口，根据任务依赖选择直接查询、ReAct 串行推理或 DAG 并行调度，自动汇总日志、Prometheus 和只读数据库证据；24 条 Agent 编排用例通过。
- **受控执行与故障恢复：** 为工具调用增加超时重试、Redis 快照恢复和 fallback，并以三级角色及审批限制高风险修复；执行后重新验证，失败转人工，7 条故障注入和 16 条修复闭环用例通过，Harness P95 为 726ms。
